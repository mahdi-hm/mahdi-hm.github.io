Hi, I'm Mahdi. I'm an engineering manager at AWS, leading a database engineering
team, where correctness isn't optional.

Coding agents have changed how my team works. Writing code got cheap,
but knowing what it should do, checking that it does, and running it
safely did not. This blog is about that shift:

- **Reliable AI**: treating agents as capable but untrusted contributors
- **Verification**: specs, invariants, property-based and differential
  testing, fuzzing, and formal methods with Lean
- **Practical tooling**: open-source tools like ast-grep that turn hard
  lessons into automated checks
- **Leading teams** through the change: roles, review, and growth

I write roughly once a month, using public tools and ideas only.
